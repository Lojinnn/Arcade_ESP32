# Arcade_ESP32

Проект делается на WROOM ESP32-D32 и на TFT дисплее с драйвером ST7789/ST7789v2.
Другие версии компонентов не предусмотрены(может произойти разрыв между процом и диспеем, 
т.к. нет вертикальной синхронизации).

версии идут таким порядком:
v0.1 это полностью сырой продукт, не оптимизирован   (23.04.26)
v0.2 недалеко ушёл, но присутствуют ачивки(надеюсь) и собирается информация о играх <-----(почти здесь)
v0.3 арканоид
v0.4 пинпонг(на двоих, не с роботом)
v0.5 профили(надеюсь получится сделать)
v0.6 настройки
v0.7-0.9 доделываем и приводим всё в нормальный вид
v1 релиз(очень надеюсь, что дойду досюда)

Проект делается с душой :)
